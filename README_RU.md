# Universal Audio Waveform Sync 8.0

Программа сопоставляет общий звук в первом канале двух дорожек, строит карту
времени и применяет её ко **всем каналам** исправляемой дорожки.
Центральный канал не подмешивается в анализ.

## Установка в Windows 11

1. Распакуйте **весь архив** в отдельную папку. Не запускайте файлы внутри ZIP.
2. Установите 64-битный Python 3.12 с [python.org](https://www.python.org/downloads/windows/).
   Поддерживается Python 3.11 или новее. При установке включите Python Launcher
   и добавление Python в PATH. Windows Store alias сам по себе Python не заменяет.
3. Установите FFmpeg и FFprobe. На [официальной странице FFmpeg](https://ffmpeg.org/download.html#build-windows)
   указаны поставщики сборок для Windows. Распакуйте выбранную доверенную сборку
   и добавьте её папку `bin` в PATH **либо** положите `ffmpeg.exe`, `ffprobe.exe`
   и необходимые DLL в `tools\ffmpeg\bin` внутри папки программы.
   Эта сборка не скачивает неизвестные EXE автоматически и не отключает проверку TLS.
4. Дважды щёлкните `SETUP_WINDOWS.cmd`. Он создаст локальную папку `.venv`, установит
   NumPy, SciPy и Matplotlib из PyPI и проверит доступность FFmpeg.
5. Если меняли PATH, откройте новое окно CMD. Проверьте:

```cmd
START_WINDOWS.cmd --check
```

В архиве есть все исходники и тесты. Python, FFmpeg, их лицензии и бинарные файлы
в архив не включены. Установка требует Интернета; обработка готовых дорожек — нет.

## Обычный запуск из папки

Положите две дорожки рядом с `START_WINDOWS.cmd`. Откройте терминал в этой папке
и выполните:

```cmd
START_WINDOWS.cmd
```

Либо дважды щёлкните этот файл. Выберите номер эталона, затем номер исправляемой
дорожки. Во втором меню нумерация начинается заново с 1.

Для другой папки:

```cmd
START_WINDOWS.cmd --directory "D:\Фильм\Звук"
```

Можно обойти меню:

```cmd
START_WINDOWS.cmd --reference "D:\Фильм\English.flac" --target "D:\Фильм\Русский.dts"
```

Исходники должны быть разными файлами. Пути с пробелами берите в кавычки.
Меню ищет файлы только в выбранной папке, без вложенных папок результатов.
Читаются форматы, поддерживаемые установленным FFmpeg, включая WAV, FLAC,
AC-3, E-AC-3, DTS, MKA, AAC, MP3. Если в MKV/MP4/MKA несколько звуковых потоков,
выберите нужный явно, иначе программа откажется выбирать за вас:

```cmd
ffprobe -v error -show_streams "D:\Фильм\movie.mkv"
START_WINDOWS.cmd --reference "D:\Фильм\movie.mkv" --reference-stream 1 --target "D:\Фильм\Русский.flac"
```

Индексы — значения `index` из FFprobe; это не номера из меню.

## Улучшение дорожки, уже полученной в v3.3

Используйте **`--refine-only`**. Тогда программа начинает с нулевой поправки,
не выполняет новое крупное выравнивание и ищет только локальные остатки до ±25 мс:

```cmd
START_WINDOWS.cmd --refine-only --reference "D:\Фильм\English.wav" --target "D:\Фильм\Русский_после_v3_3.wav"
```

Если вы хотите выбирать файлы из меню:

```cmd
START_WINDOWS.cmd --refine-only
```

Для особенно коротких локальных проблем можно увеличить плотность измерений:

```cmd
START_WINDOWS.cmd --refine-only --step 1
```

По умолчанию шаг — 5 с. При подтверждённых нелинейных остатках программа может
автоматически уменьшить его до 2,5 и 1,25 с. Каждый такой этап имеет собственную
проверочную сетку. Более плотный анализ занимает больше времени.
Проблема короче расстояния между окнами может остаться незамеченной.
Для надёжной проверки используйте достаточно длинные фрагменты, желательно от 10 с.

## Что происходит

1. FFmpeg декодирует **канал с индексом 0** каждого выбранного звукового потока
   в float32 PCM при 48 кГц. В обычном 5.1 это левый фронтальный канал.
2. В обычном режиме программа ищет крупное смещение по RMS-огибающей и проверяет
   несколько скоростей, включая 24/25, 25/24, 23,976/25. Затем уточняет тренд
   и проверяет его на других временных точках. Радиус крупного поиска — ±120 с;
   при необходимости задайте `--search-radius 300`.
3. Микропоиск сопоставляет PCM с учётом **скорости текущей карты**. Разные
   подокна должны согласоваться. Если полный спектр загрязнён другим миксом,
   требуется согласие минимум двух частотных полос. Периодические сигналы,
   тишина, слабые и противоречивые совпадения не создают поправку.
4. Поправки проверяются на отдельных окнах. Отклонённый якорь разрывает область
   коррекции; сомнительные соседние поправки отменяются. Для устойчивого
   постоянного остатка проверяется также продолжение коррекции до краёв.
5. Все каналы исходного TARGET декодируются и один раз обрабатываются одной
   картой с оконным sinc-ресемплированием и фильтрацией против алиасинга.
   Итоговая громкость не нормируется, каналы не сводятся в моно.
6. Готовый WAV снова декодируется. Измеряются реальные остатки, проверяются
   формат, раскладка каналов и длительность. Провал проверки блокирует выдачу
   `SYNCED_TARGET.wav`.

Программа не применяет многократное lossy-кодирование, `atempo` или `concat`
к сотням кусков. Изменение скорости ресемплированием меняет и высоту тона.
Если одна версия уже растянута с сохранением высоты тона, совпадение PCM может
быть недостаточным: тогда программа не должна обещать точность по отсчётам.

## Результаты

Каждый запуск создаёт новую папку `<имя>_WAVEFORM_SYNC_<дата>`. Старые результаты
не перезаписываются. Можно указать `--output "D:\Результаты\Новая_папка"`;
эта папка должна ещё не существовать.

| Файл или статус | Значение |
| --- | --- |
| `SYNCED_TARGET.wav` / `VERIFIED_PCM` | Фактический выход проверен по PCM на контрольных участках. |
| `COARSE_ALIGNED_REVIEW.wav` / `VERIFIED_ENVELOPE_ONLY` | Подтверждено только крупное выравнивание по огибающей. Нужны прослушивание и проверка в Audacity. |
| `NO_CONFIRMED_IMPROVEMENT` | В режиме уточнения улучшение не доказано; новый звук не создаётся. |
| `REJECTED`, `BLOCKED` | Результат не прошёл проверку или данных недостаточно. Синхронизированный файл не выдаётся. |
| `REPORT_RU.txt`, `REPORT.json` | Человекочитаемый отчёт и полные измерения. |
| `BASE_MAP.json`, `FINAL_MAP.json`, `FINAL_MAP.csv` | Крупная и действительно применённая карты. |
| `MICRO_MEASUREMENTS.csv`, `MICRO_HOLDOUT.csv` | Измерения и решения защиты, включая отменённые попытки. |
| `ACTUAL_OUTPUT_VALIDATION.csv` | Остатки фактически декодированного результата. |
| `graphs` | Волны, огибающие, карты, скорость, достоверность, остатки и увеличенные сравнения. |

Выход — WAV/RF64 с 32-битным PCM с плавающей точкой, с исходной частотой
дискретизации TARGET и всеми его каналами. Он открывается в Audacity.
Это предотвращает новое сжатие с потерями и обрезание пиков интерполяции.
Это **не** побитовая копия исходного DTS/AC-3 и не восстановление информации,
уже потерянной в исходном сжатии. Для фильма позднее можно отдельно выбрать
нужный кодек. Автоматическое повторное AC-3/AAC-кодирование намеренно убрано.

Код завершения 0 — проверенный PCM или сохранение исходника без изменений;
2 — требуется проверка/данных недостаточно; 1 — ошибка запуска;
130 — отмена пользователем.

## Диск и память

Для 2 часов, 48 кГц, 5.1: временный многоканальный float32 занимает около
7,7 ГиБ, итоговый WAV — ещё около 7,7 ГиБ; монофайлы анализа и проверки вместе
занимают около 3,9 ГиБ. Планируйте минимум 22–25 ГиБ свободного места.
Время зависит от процессора, длины, числа каналов и плотности анализа.
Дорожки не загружаются целиком в оперативную память: PCM доступен через memmap,
ресемплирование выполняется блоками. Временные PCM удаляются после завершения.
Параметр `--keep-work` сохраняет монофайлы анализа для диагностики.

## Точность и монтаж

При 48 кГц один отсчёт — **20,833 мкс**. Дробный пик корреляции позволяет
оценивать положение между отсчётами, но не доказывает физическую точность
1 мкс. Разные переводы, миксы, реверберация, фильтры и кодеки могут давать
разные формы волн даже при правильном времени.

Защита проверяет выбранные окна, а не каждый отсчёт фильма. Гарантировать,
что произвольная дорожка нигде не станет хуже, нельзя. Здесь исходники всегда
сохраняются, неопределённость отражается в отчёте, а обнаруженная регрессия
не превращается в файл со статусом «готово».

Монтажный скачок нельзя безопасно «сгладить» растяжением. Автоматический режим
останавливается при таком подозрении и сохраняет измерения. При известных
границах используйте [явную карту монтажа](docs/EDIT_MAP_RU.md).
Программа может пропустить лишний кусок TARGET или поставить тишину там,
где в TARGET нет сцены эталона. Создать отсутствующий русский перевод она не может.

```cmd
.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
```

В Linux/macOS: `python3 -m venv .venv`, затем
`.venv/bin/python -m pip install -r requirements.txt`,
`.venv/bin/python start_sync.py`.
