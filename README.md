# Universal Audio Waveform Sync — Modular 6.9.9

Восстановлены интерфейс, меню, 12 этапов, проценты выполнения и графики
исходной сборки **6.9.1**. Основной поиск и построение карты времени используют
её исходные модули. После основного рендера добавлено отдельное PCM-уточнение
остаточного сдвига с проверкой независимых окон и записанного файла.

**Сборка 8.0 заменена этой версией.** Её широкий поиск и остановка всего
процесса из-за длинного неподтверждённого участка здесь не используются.

[Скачать ZIP 6.9.9](https://raw.githubusercontent.com/Kilych1978/project_1_git/refs/heads/main/releases/Universal_Audio_Waveform_Sync_modular_v6.9.9.zip)

[Инструкция для Windows 11](README_RU.md) ·
[Разбор отчёта 28.10 и исправления](docs/FIX_20261028_RU.md) ·
[Проверки](docs/TEST_RESULTS_RU.md)

Для установки: `SETUP_WINDOWS.cmd` один раз. Аудиофайлы положите рядом
со `start_sync.py`.

- Дорожка **уже обработана v3.3**, остались миллисекунды: `MICRO_REFINE.cmd`.
  Он уточняет выбранный исходник напрямую, без повторной крупной синхронизации.
- Нужна синхронизация с самого начала: `START_WINDOWS.cmd`, прежние 12 этапов.
- Фрагменты конкретных мест Audacity без полного прогона: `DIAGNOSE_POINTS.cmd`.

Оба режима начинают новый анализ выбранных дорожек. Старые папки,
карты, отчёты и PCM-файлы не нужны и не загружаются. Все рабочие файлы
создаются заново в отдельной папке результата текущего запуска.

В 6.9.9 исправлен отказ от всей дополнительной карты из-за нескольких
проблемных окон. После локальных масок изолируются не прошедшие проверку
участки, а остальные поправки проверяются повторно. Три отмеченных места
проверены с координатами и якорями полного фильма на присланном звуке.

Сохранено исправление численного сбоя на длинной карте времени. Отказ дополнительного
поиска сохраняет проверенный базовый PCM-план текущего запуска; запись WAV
всё равно проходит независимую проверку.

Для пропущенных отрезков добавлено измерение на сдвинутой сетке и проверка
согласованных частотных якорей. Ранее подтверждённый PCM сохраняется при
отказе дополнительной фазы.

Если подтверждённого улучшения нет, новый аудиофайл **не создаётся**.
Исходник используется напрямую, отчёты сохраняются. Отклонённые аудиокандидаты
из `pass_1–3` удаляются; диагностические отчёты этих проходов остаются.

Согласованные отрезки получают собственную скорость и задержку.
Границы соединяются коротким плавным смешиванием; полезная поправка больше
не требует искусственного растяжения всего соседнего участка. Уже проверенные
улучшения сохраняются. Сравниваются реальные PCM до и после записи WAV.

Строка прогресса учитывает ширину терминала. В конце автоматически собираются
все отчёты, карта, графики, журнал и короткие фрагменты в `REPORT_BUNDLE*.zip`;
каждый архив не больше 25 МиБ. Разрядность PCM и исправление RF64 сохранены.
[Что исправлено](docs/FIX_20261028_RU.md) · [Измеренные результаты](docs/TEST_RESULTS_RU.md).

Проверка установки: `python start_sync.py --check`.

Проверки разработчика:

```text
python self_test_v6_8.py
python self_test_v6_9.py
python -m unittest discover -s tests -t . -v
python -m tests.full_modular_smoke /tmp/wavesync-smoke .275
```

Измерения подтверждают результат в проверенных окнах с общим звуком.
Точность в одну микросекунду на произвольных разных звуковых миксах не гарантируется.
