# Universal Audio Waveform Sync 8.0

Синхронизация аудиодорожек по **первому каналу**. Все каналы исправляемой дорожки
получают одну общую карту времени. Исходные файлы не изменяются.

Подробная инструкция: [README_RU.md](README_RU.md).

Windows 11: один раз запустите `SETUP_WINDOWS.cmd`, затем `START_WINDOWS.cmd`.
Нужны Python 3.11+ и FFmpeg/FFprobe. Python и FFmpeg не включены в архив.

Для уже сведённой дорожки из v3.3:

```cmd
START_WINDOWS.cmd --refine-only
```

Точность проверяется на фактическом выходном файле; неподтверждённые измерения
не считаются нулевой ошибкой. Гарантия 1 мкс для разных миксов невозможна.
Монтажные скачки требуют явных границ, см. [инструкцию](docs/EDIT_MAP_RU.md).

Проверки разработчика:

```text
python -m unittest discover -s tests -t . -v
```
