# «Катала»: пробное исправление вертикальных полос

Это файлы одной проверочной пробы, а не готовая программа для полного фильма.

## Как получить видео в Windows 11

1. Скачайте ZIP-архив этого выпуска целиком.
2. Нажмите правой кнопкой по ZIP и выберите **Извлечь всё**.
3. Откройте распакованную папку и запустите **ASSEMBLE_VIDEO.cmd**.
4. После сообщения **ГОТОВО** рядом появится
   **Katala_sample_REPAIRED_FINAL.mkv**. Откройте его в MPC-HC или другом
   плеере с поддержкой FFV1.

Файл разбит внутри архива из-за ограничения GitHub на размер одного файла.
Сборка только объединяет байты и проверяет SHA-256. Она ничего не скачивает,
не перекодирует видео и не требует установки программ или прав администратора.

**Katala_BEFORE_AFTER.mp4** — небольшое сравнение увеличенного участка:
слева до обработки, справа после. Для него сборка не требуется.

## Проверенный результат

- 2962×2160, 24 кадра/с, 167 кадров, длительность 6,916 с.
- Исходные временные метки кадров, формат YUV420p, диапазон TV и BT.709 сохранены.
- Видео сохранено FFV1 без потерь. Отсчёты вне масок исправления совпадают точно.
- Жёлтая полоса убрана, несколько менее заметных линий также обработаны.
- Детали непосредственно в полосах восстановлены по соседним отсчётам;
  это оценка, а не доказанное восстановление первоначально утраченных пикселей.
- Исследованный образец не доказывает качество автоматического обнаружения
  полос во всех остальных сценах фильма.
