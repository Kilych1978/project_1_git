# Сборка Modular 6.9.16

Дополнительное сопоставление общего звука для разных каналов и миксов.
Выбранные сигналы проверяются отдельными событиями и готовым WAV.
Надёжный прежний путь и точный PCM-алгоритм сохранены.

[Скачать ZIP](https://raw.githubusercontent.com/Kilych1978/project_1_git/refs/heads/main/releases/Universal_Audio_Waveform_Sync_modular_v6.9.16.zip)

Распакуйте в новую папку, положите исходные дорожки рядом со start_sync.py,
выполните SETUP_WINDOWS.cmd один раз. Затем обычный START_WINDOWS.cmd.
Старые папки результата не требуются, новые способы выбираются автоматически.
Контрольная сумма находится рядом в файле .zip.sha256.

Спектральное выравнивание не гарантирует совпадение PCM до отсчёта;
полной пользовательской дорожки в среде нет.
[Проверенные результаты и ограничения](../docs/COARSE_6_9_16_RU.md).
Если улучшение не подтверждено, дубликат аудио не создаётся.

Архивы REPORT_BUNDLE*.zip создаются автоматически, каждый до 25 МиБ.
Для сбора исходных фрагментов со всеми каналами — COLLECT_SOURCE_CLIPS.cmd.
Для анализа уже почти синхронного звука остаётся отдельный MICRO_REFINE.cmd;
для первоначальной синхронизации нужен START_WINDOWS.cmd.
