# Сборка Modular 6.9.10

[Скачать ZIP](https://raw.githubusercontent.com/Kilych1978/project_1_git/refs/heads/main/releases/Universal_Audio_Waveform_Sync_modular_v6.9.10.zip)

Скачайте архив и распакуйте в новую папку. Инструкция внутри — README_RU.md.
Контрольная сумма находится рядом в файле `.zip.sha256`.

Положите две дорожки рядом со `start_sync.py`, выполните `SETUP_WINDOWS.cmd`
один раз, затем запускайте `START_WINDOWS.cmd`. Для дорожки после v3.3
с небольшим остаточным сдвигом есть `MICRO_REFINE.cmd`.
Каждый запуск работает с выбранными аудиофайлами и создаёт новые рабочие
данные. Папки, карты и отчёты от предыдущих запусков не требуются.

Если улучшение не подтверждено, новый аудиофайл не создаётся: остаются
исходник и отчёты. Сбой на длинной карте времени исправлен.
В 6.9.10 добавлены сквозная проверка полного PCM-плана до многоканальной
записи и восстановление целых проблемных окон вместе со всеми внутренними
кривыми. Новые границы проверяются повторно, пороги качества сохранены.
[Причина и проверенные изменения](../docs/FIX_20261111_RU.md).

Для диагностики конкретных мест без полного прогона — `DIAGNOSE_POINTS.cmd`.
Архивы `REPORT_BUNDLE*.zip` создаются автоматически, каждый не больше 25 МиБ;
приложите все тома к сообщению.
