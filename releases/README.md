# Готовая сборка 8.0

[Скачать ZIP](https://github.com/Kilych1978/project_1_git/raw/refs/heads/codex/wavesync-v8/releases/Universal_Audio_Waveform_Sync_v8.0.zip)

В ZIP находятся программа, CMD-файлы запуска, русская инструкция, тесты
и примеры графиков. Python и FFmpeg устанавливаются отдельно.

1. Скачайте и распакуйте ZIP целиком.
2. Прочитайте `README_RU.md` внутри распакованной папки.
3. Запустите `SETUP_WINDOWS.cmd`, затем `START_WINDOWS.cmd`.
4. Для дорожки, уже обработанной v3.3, используйте `START_WINDOWS.cmd --refine-only`.
