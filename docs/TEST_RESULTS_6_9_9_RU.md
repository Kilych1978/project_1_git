# Проверки Modular 6.9.9 — 28.10.2026

Linux, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8,
FFmpeg 7.1.5. Прямого запуска Windows 11 здесь не было.

## Автоматические проверки

76 unittest-тестов, 9 исходных safety/validation-проверок и 6 исходных
проверок микроуточнения прошли. Журналы: `TEST_LOG.txt`,
`LEGACY_TEST_LOG.txt`, `LEGACY_MICRO_TEST_LOG.txt`.

Новая регрессия воспроизводит исчерпание шести проверок из-за удалённой
проблемной границы. Без исправления удачная поправка другого участка
терялась бы вместе со всей дополнительной картой. Теперь проверены:

- сохранение и повторная проверка независимой удачной поправки;
- изоляция непрошедшего окна и всех пересекающих его участков;
- разделение двух независимых участков внутри одного исходного PCM-слоя;
- побитовая эквивалентность PCM до и после такого разделения;
- сохранение кеша для окна, на которое разделение не влияет;
- запись настоящего шестиканального S16 WAV с сохранённой удачной поправкой;
- отсутствие изменения исходника и точное сохранение исходного звука
  в исключённом окне.

Предыдущие проверки скорости, дробных задержек, монтажа, другого микса,
полярности, тишины, вложенных PCM-слоёв, 44,1/48 кГц, WAV/RF64, прогресса,
диагностических ZIP и отсутствия копии без улучшения также прошли.

## Проверка на данных полного запуска

Все пять диагностических ZIP прошли CRC; все 19 восстановленных файлов
проверены по SHA-256. Содержимое десяти пар входных монофрагментов совпадает
с ранее присланными данными. Построение S16 WAV по сохранённой полной карте
6.9.8 побайтно совпало с реальным готовым файлом пользователя на внутренних
областях этих десяти фрагментов; крайние 350 мс не сравнивались, поскольку
за границами вырезки нет исходных аудиоотсчётов.

Дополнительный кандидат построен из измерений полного запуска. При проверке
сохранены абсолютные координаты фильма и фаза исходной сетки. Измерения
не начинались с нуля каждого короткого фрагмента. Проверены десять текущих
отрезков и три ранее присланных отрезка конкретных мест Audacity.

Записанные в S16 WAV результаты в отмеченных точках:

| Время | Старый результат, мс | Локальный кандидат, мс |
| --- | ---: | ---: |
| 7:28.755 | 10.707617 | 0.000307 |
| 52:05.916 | 5.017154 | 0.007436 |
| 52:15.301 | 5.656523 | 0.004685 |

Все три оценки корреляционного пика меньше одного отсчёта 48 кГц
(0,020833 мс). На доступных интервалах 4 848 проверок записанного PCM
относительно сохранённой базовой карты прошли без регрессий.

Причина глобального отказа отдельно покрыта регрессионным тестом с удалённой
проблемной границей. Проверка реальных фрагментов показывает возможность
исправить отмеченные места при сохранении их поправок.
Числа и область проверки: `REPORT_ANALYSIS_20261028.json`.

## Что пока не проверено

Новый полный WAV фильма не записывался: в облаке есть отчёты и короткие
аудиофрагменты, а не полные дорожки. Полученные локальные оценки не являются
гарантией микросекундной точности во всех остальных местах или разных миксах.
Все пороги качества и проверка реального WAV сохранены.

Полный 12-этапный прогон прежней 6.9.8 на синтетических шестиканальных
DTS/WAV описан в `TEST_RESULTS_6_9_8_RU.md`; это историческая проверка,
не новый полный прогон 6.9.9.

Обычный запуск 6.9.9 заново читает выбранные аудиодорожки. Сохранённая
полная карта использовалась здесь для диагностики ошибки; рабочая программа
не читает старые папки, отчёты и PCM автоматически.

Код и численные результаты публикуются без пользовательских аудиофрагментов
и личных путей. Новый ZIP проверяется по манифесту и после распаковки в путь
с кириллицей и пробелами. CMD-файлы сохранены в UTF-8 с CRLF.

```text
python -m unittest discover -s tests -t . -v
python self_test_v6_8.py
python self_test_v6_9.py
```
