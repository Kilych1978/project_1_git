# Устройство сборки

| Модуль | Ответственность |
| --- | --- |
| `start_sync.py` | Проверка версии Python, понятные сообщения об ошибках, точка запуска. |
| `wavesync/cli.py` | Меню, параметры, этапы обработки, управление файлами и статусом результата. |
| `audio.py` | FFprobe, выбор конкретного потока, FFmpeg, первый канал и многоканальный PCM. |
| `features.py` | Блочное построение RMS-огибающей. |
| `alignment.py` | FFT-поиск, гипотезы скорости, робастный тренд, независимая крупная проверка. |
| `model.py` | Единственная система координат и отдельные монтажные участки. |
| `micro.py` | Поиск дробного лага по PCM, частотные полосы и согласование подокон. |
| `dsp.py` | Нормированная корреляция и оконное sinc-ресемплирование. |
| `guard.py` | Отдельная проверочная сетка, карантин поправок и проверка декодированного выхода. |
| `render.py` | Блочный однократный рендер всех каналов. |
| `reports.py` | Русские отчёты, CSV/JSON и графики фактического результата. |
| `config.py` | Пороги, ограничения и параметры анализа. |

Во всех модулях: `reference_time = target_time + offset`. Поправка к карте
и остаточная ошибка — разные величины. Валидатор не переиспользует абсолютное
смещение как остаток.

Крупное сопоставление работает по огибающей, микропоиск — по PCM, пересчитанному
с учётом скорости карты. Поиск и рендер используют один интерполяционный kernel.
Частотные полосы помогают при разных миксах, но должны согласоваться по задержке.
Положение каждого принятого якоря включается в карту явно; сетка в одну секунду
не округляет его время. Отклонённые якоря разрывают области уточнения.

Подтверждённая микропоправка интерполируется PCHIP: кривая проходит через
якоря и сохраняет форму между ними. Крупная карта вне этих областей остаётся
прежней. Проверяются также экстремумы мгновенной скорости между узлами,
а не только средняя скорость сегмента. Рендер численно обращает именно эту
кубическую карту, без отдельной приближённой обратной кривой.

Если остаточное изменение скорости смазывает длинное PCM-окно, микропоиск
проверяет более короткое окно 40 мс. Требования к уникальности пика и согласию
подокон сохраняются. Измерение в центре якоря не усредняется с соседями;
соседние измерения проверяют его правдоподобие.

Уменьшение шага создаёт новую пару обучающей и проверочной сеток. Длина и
расстояние подокон уменьшаются вместе с шагом, чтобы эти области PCM не
перекрывались. Краевые проверки используют короткие окна отдельно от обучения.

Финальная защита оценивает **декодированный выход**. Крупное совпадение огибающих
может подтвердить порядок сцен при слабом общем PCM; такой результат получает
отдельное имя `COARSE_ALIGNED_REVIEW.wav` и требует ручной проверки.
Неподтверждённые PCM-остатки не записываются как нули.

Файлы результатов создаются в новом каталоге. Промежуточный `CANDIDATE_TARGET.wav`
переименовывается только после проверки и удаляется при отклонении.
Временные memmap закрываются до удаления, что необходимо для Windows.
