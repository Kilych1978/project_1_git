СБОР ЗВУКА ТРЁХ ТОЧЕК ДЛЯ ДИАГНОСТИКИ

Это только сборщик фрагментов, не новая версия синхронизатора.
Python и FFmpeg уже должны быть установлены. Дополнительные библиотеки не нужны.

1. Распакуйте два файла сборщика в папку, где находятся эталонная дорожка
   и входная дорожка после v3.3. Можно в папку действующего скрипта рядом с дорожками.
2. Запустите СОБРАТЬ_ЗВУК.cmd двойным щелчком.
3. Выберите эталон, затем входную дорожку после v3.3.
4. Дождитесь завершения. Декодируется только первый канал до последней точки;
   расчёт синхронизации и многоканальный рендер не выполняются.
5. Пришлите появившийся AUDIO_POINT_DIAGNOSTICS_дата_время.zip.

Настроены точки 7:28.755, 52:05.916, 52:15.301; вокруг каждой извлекается
по 8 секунд. Прочие точки можно задать аргументами CMD либо при запуске Python.
Полные дорожки в ZIP не включаются и не изменяются. Никакой автоматической
отправки нет. Временные файлы полного PCM не создаются. Для точности DTS
декодируется последовательно с начала, без неточного перехода по времени.
