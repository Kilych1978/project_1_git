# Проверки сборки Modular 6.9.3

Выполнены 14.10.2026 в Linux: Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0,
Matplotlib 3.10.8, FFmpeg 7.1.5. Native Windows в этой среде отсутствует.

## Присланный реальный звук

Проверены все восемь пар четырёхсекундных монофрагментов первого канала
из DIAGNOSTIC_CLIPS.zip. Исходники прочитаны как S16, 48 кГц. Для каждой
пары выполнены поиск, независимая проверка, настоящий рендер FFmpeg в float32
WAV, повторное декодирование и проверка готового звука. Четыре пары с тишиной
оставлены без изменений. Остальные четыре получили проверенное улучшение.

до и после измерены те же центральные события. Это оценки по корреляции,
а не доказательство абсолютной точности до микросекунды.

В двух последних фрагментах обнаружены короткие скачки остатка порядка 2–9 мс.
Не все переходы исправлены. На принятых проверочных окнах ухудшений сверх
одного аналитического отсчёта не найдено; часть сомнительных мест сохраняет
основной результат. Между проверочными окнами такая гарантия не доказана.
Полных дорожек фильма в этой среде нет, поэтому весь фильм здесь не проверен.

Исходные аудиофайлы сохранены. Пользовательский звук, частные отчёты
и изображения его волн не входят в публичный репозиторий или сборку.
Повторение проверки со своими фрагментами:

    python -m tools.verify_diagnostic_clips EXTRACTED_CLIPS NEW_OUTPUT_DIRECTORY

## Автоматические проверки

- **36 тестов unittest — прошли.** Лог: TEST_LOG.txt.
- **9 исходных проверок safety/validation 6.8 — прошли.** Лог: LEGACY_TEST_LOG.txt.
- **6 исходных проверок микроуточнения 6.9.1 — прошли.** Лог: LEGACY_MICRO_TEST_LOG.txt.

Проверены сдвиги 6/10 мс с шестью каналами, дробный отсчёт, плавный локальный
сдвиг, разная громкость, полярность и частотные миксы, неоднозначный тон,
тишина и посторонний звук. Проверены реальные запись/декодирование, исходные
44,1/48 кГц, единая карта всех каналов и отсутствие клиппирования float32.

Новые проверки воспроизводят ошибки отказавшей версии: единичный недопустимый
переход не отменяет весь фильм; неудачная плотная сетка сохраняет предыдущую
подтверждённую карту; известная нелинейная карта не портит проверку часов;
обратный PCM-поиск подтверждает настоящий скачок. Отдельная проверка вводит
локальный отказ в декодированном кандидате и проверяет повторный рендер
с сохранением удалённых от него поправок и исходных файлов.

Сохранены проверки 1051 числового измерения из первого отчёта, 35 секунд
без общего звука, ненулевой основной карты и безопасного перехода tempo.
Новый запуск --micro-only проверен через прежнее меню выбора дорожек,
проценты, четыре этапа и запись шестиканального результата.

## Полный запуск программы

Все 12 этапов прежнего интерфейса пройдены на сгенерированных четырёхминутных
дорожках: эталон DTS, исправляемый шестиканальный WAV, начальный сдвиг 275 мс.
Центральный канал намеренно содержит другой звук. Отсутствующая длительность
DTS в метаданных моделируется явно. Проверки исходных SHA-256, длительности,
числа каналов и наличия прежних графиков прошли. PCM-уточнение проверено
на 1597 изменённых окнах; медианный оценённый остаток меньше одного отсчёта.
Лог: FULL_PIPELINE_LOG.txt. Примеры графиков: examples/restored_6_9_3.

Это синтетический тест; его точность не переносится автоматически на фильм.

## Windows 11

Сохранены SETUP_WINDOWS.cmd, START_WINDOWS.cmd и локальная .venv.
Добавлен MICRO_REFINE.cmd. CMD-файлы имеют CRLF, учитывают пробелы в пути,
UTF-8 и возможность расположить FFmpeg/FFprobe в tools/ffmpeg/bin.
Для Python 3.14 x64 ранее проверена загрузка всех требуемых Windows wheels.
Функциональные проверки новой программы выполнялись в Linux; непосредственный
запуск CMD под Windows в этой среде не проводился.
