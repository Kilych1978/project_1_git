# Терминальный интерфейс 6.9.13

Изменён только вывод в терминале. Численные алгоритмы успешной 6.9.12
сохранены: поиск, сетки, пороги, карты, интерполяция, откаты и проверки WAV.

Сообщения интерфейса — на английском; русские TXT-отчёты сохранены.
Названия файлов и пути не переводятся. Часы `HH:MM:SS` используются для
текущей позиции и ETA. Миллисекундные измерения в отчётах не менялись.

Названия проверок описывают операцию: `BASELINE REGRESSION CHECK`,
`SHARED REFERENCE TIMELINE`, `INDEPENDENT CHECKPOINTS`. Счётчики прохода,
сетки и размер окна вынесены отдельно. Соседние сетки одной операции
не повторяют её полный заголовок и неизменную область проверки.

Сохранность расчётов проверена относительно коммита `7c4bdf3` версии 6.9.12:

- 34 защищённых модуля совпадают побайтно, включая весь `pcm_core`,
  построение карт, защиту, декодирование и рендер.
- В `pcm_refiner.py` изменён только класс вывода `_ProgressCallback`.
  AST остальных определений совпадает с 6.9.12.
- В `common.py` изменён только вывод `Progress` и его импорты.
  Остальные определения совпадают на уровне AST.
- В `diagnostics.py` добавлена только обёртка терминального перевода;
  в `start_sync.py` — её включение. Формирование данных отчётов не менялось.

Контрольные суммы и результаты сравнения:
`ENGINE_EQUIVALENCE_6_9_13.json`.

Пройдены 13 проверок интерфейса, ввода и диагностических архивов.
Дополнительно проверен интерактивный микро-режим с шестиканальным результатом.
Непосредственный запуск Windows CMD в Linux-среде не выполнялся.

Для уже успешно синхронизированной пары используйте тот же режим запуска.
Повторно обрабатывать готовую дорожку ради нового оформления не нужно.
