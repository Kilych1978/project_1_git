# Явные границы монтажа

Автоматический режим не должен маскировать вырезанную сцену плавным изменением
скорости. При подтверждённом крупном скачке он останавливается и записывает
измерения в `FAILED_STAGE.csv` и `REPORT.json`.

Когда монтажные границы известны, создайте JSON-файл с отдельными участками:

```json
{
  "pieces": [
    {"target": [0.0, 100.0], "reference": [0.0, 100.0]},
    {"target": [102.0, 200.0], "reference": [100.0, 198.0]}
  ],
  "notes": ["В TARGET лишние две секунды между 100 и 102 с."]
}
```

Значения — секунды от начала декодированного звукового потока. Каждый список
должен содержать минимум две строго возрастающие точки; внутри участка
действует линейная интерполяция. Соответствующие точки имеют одинаковые индексы.

В этом примере лишние две секунды TARGET пропускаются. Если в эталоне есть
сцена, которой нет в TARGET, задайте разрыв **reference**:

```json
{
  "pieces": [
    {"target": [0.0, 100.0], "reference": [0.0, 100.0]},
    {"target": [100.0, 200.0], "reference": [102.0, 202.0]}
  ]
}
```

Между 100 и 102 с выходной дорожки будет тишина. Каналы эталона в выход не
копируются, перевод не генерируется. Такая тишина — явное следствие заданной
карты; она не считается восстановлением отсутствующего содержания.

Запуск:

```cmd
START_WINDOWS.cmd --reference "D:\Фильм\English.wav" --target "D:\Фильм\Русский.wav" --map-json "D:\Фильм\edit_map.json"
```

Участки не должны перекрываться ни по TARGET, ни по REFERENCE. Локальная скорость
внутри каждого участка ограничена диапазоном ±8%. Ручная карта тоже проходит
проверку, микропоиск и проверку готового файла. Она не отключает защиту.

Пример рассчитан на соответствующие реальные сцены: два произвольных списка
точек не подтверждают совпадение аудио. Уточняйте границы по общим звукам,
проверяйте соседние реплики и прослушивайте стыки. Неподтверждённые или слишком
короткие участки могут заблокировать обработку.
