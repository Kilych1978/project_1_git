# Проверки Modular 6.9.6 — 20.10.2026

Среда: Linux, Python 3.12, NumPy 2.3.5, SciPy 1.17.0,
Matplotlib 3.10.8, FFmpeg 7.1.5. Windows и foobar2000 непосредственно
в этой среде не запускались.

## Автоматические и функциональные проверки

- 45 unittest-тестов: `TEST_LOG.txt`.
- 9 исходных safety/validation-проверок: `LEGACY_TEST_LOG.txt`.
- 6 исходных проверок микроуточнения: `LEGACY_MICRO_TEST_LOG.txt`.
- Дополнительная проверка отката и WAV/RF64 после окончательных изменений:
  `FINAL_TARGETED_TEST_LOG.txt`.
- Полный запуск всех 12 этапов: `FULL_PIPELINE_LOG.txt`.

Полный прогон использует новые четырёхминутные DTS/WAV с шестью каналами,
сдвигом 275 мс и разным центральным каналом. Проверяются неизменность SHA-256
обоих исходников, длительность, шесть каналов, сохранение S16, обычный RIFF,
размер около исходного, исходные графики и проверенный PCM-результат.

Новые тесты воспроизводят:

- `fact=0xFFFFFFFF` у float-RF64 и исправление настоящего счётчика отсчётов;
- заголовок RF64 размером около 5,6 ГиБ с разреженными аудиоданными и
  длительностью 87:32,010667 — это проверка заголовка, не рендер полного фильма;
- сохранение шестиканального S16, размера и точного PCM при единичной карте;
- сохранение основной кривой при отмене дополнительной;
- восемь неудачных проходов с сохранением независимой безопасной поправки;
- отказ дополнительной карты с последующей реальной проверкой и записью
  основного PCM-кандидата;
- отказ основного кандидата при ошибке, обнаруженной только плотной сеткой:
  возврат к более редкой сетке не скрывает известное ухудшение;
- осторожный прогноз одного пропуска между согласованными измерениями.

Существующие проверки покрывают дробные сдвиги, 6/10 мс, полярность,
разные миксы, периодический тон, тишину, посторонний звук, 44,1/48 кГц,
шесть каналов, нативный рендер и сохранность исходников.

## Ранее присланные звуковые фрагменты

Повторно обработаны десять восьмисекундных пар первого канала. Восемь
получили проверенную поправку, в двух безопасная поправка не подтверждена.
Каждый принятый файл записан, декодирован заново и проверен относительно
исходного звука. Исходные SHA-256 сохранены. Проверки не обнаружили ухудшения
сверх одного отсчёта анализа в проверяемых окнах. Это не проверка каждого
промежутка между окнами и не обещание точности в одну микросекунду.

Число контрольных окон и их сетка отличаются от 6.9.5, поэтому сравнивать
только медианы разных версий как одну и ту же выборку нельзя. Максимум

## Границы проверки

Свежий архив 20.10 содержит карты, метаданные и отчёты; аудио четырёх
отмеченных в Audacity мест в нём нет. Их причины исследованы по измерениям,
но готовый звук этих четырёх мест здесь непосредственно не проверен.
Полных дорожек фильма в облаке также нет.

Запуск в новой папке работает только с выбранными аудиофайлами. Старые
папки, карты и кэши не загружаются. CMD-файлы сохраняют UTF-8, CRLF,
поддержку кириллицы и пробелов; непосредственного запуска Windows не было.

Для повторения:

```text
python -m unittest discover -s tests -t . -v
python self_test_v6_8.py
python self_test_v6_9.py

python -m tools.verify_diagnostic_clips EXTRACTED_CLIPS NEW_OUTPUT_DIRECTORY
```
