# Результаты проверки сборки 8.0

В чистом виртуальном окружении выполнено **35 тестов, все прошли**.
Команда: `python -m unittest discover -s tests -t . -v`.
Полный журнал: [TEST_LOG.txt](TEST_LOG.txt). Пропущенных тестов нет.

Среда испытаний: Linux x86_64, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0,
Matplotlib 3.10.8, FFmpeg/FFprobe 7.1.5. Основные версии зафиксированы
в `requirements.txt`; полный список установленного окружения приложен
в `PYTHON_PACKAGES_TESTED.txt`.

| Проверка | Подтверждённый результат |
| --- | --- |
| Сдвиги +6, +10 и −6 мс | Карта восстанавливает известный сдвиг с ошибкой менее 0,1 отсчёта в этих искусственных примерах. |
| Дробный сдвиг 6,0037 мс | Ошибка измерения менее 0,3 отсчёта. |
| Крупный сдвиг | Проверены поиск 1,275 с и полный рендер при 0,275 с. |
| PAL/film, скорость 25/24 | Проверены оценка карты и полный FFmpeg-рендер с проверкой фактического выхода. |
| Плавно меняющаяся локальная ошибка до 10 мс | Проверены плотное уточнение и автоматическое уменьшение шага; медиана подтверждённых остатков менее одного отсчёта. |
| Разные низкочастотные миксы | Общий сигнал найден по согласованным частотным полосам. |
| Уже синхронная дорожка | Новое перекодирование не выполняется. |
| Тишина, чистый периодический тон, разные дорожки | Ложная поправка не применяется; несопоставимая пара не создаёт синхронизированный выход. |
| Заведомо ложные «сильные» якоря | Независимые окна отменяют их. |
| Обучающие и проверочные окна | Подтверждено отсутствие перекрытия PCM-областей при шагах 0,5, 1, 2 и 5 с. |
| Шесть каналов 5.1 | Все получают одну карту; порядок, раскладка и частота сохраняются. |
| Отличающийся центральный канал | Первый канал извлекается напрямую, без подмешивания центра. |
| 44,1 кГц и float-пики выше 1 | Частота сохраняется, пики не клиппируются. |
| Сжатие времени | Проверена фильтрация против алиасинга. |
| Явные границы монтажа | Проверены пропуск лишней сцены, тишина в разрыве и полный запуск с JSON-картой. |
| Монтажный скачок без границ | Автоматический рендер останавливается, скачок не размазывается растяжением. |
| Кубическая микропоправка | Проверены сериализация, точное численное обращение и экстремумы скорости между якорями. |
| Испорченный выход | Проверены неверный остаточный сдвиг и потеря ранее измеримого сигнала; оба результата отклоняются. |
| Полный запуск с графиками | Созданы WAV, русские отчёты, семь обзорных графиков и увеличенные сравнения реального выхода. |
| Исходники и старые результаты | Хеши исходников сохраняются; существующий каталог результатов не перезаписывается. |
| Отмена и сбой графиков | Отмена удаляет новый выход; ошибка графиков отдельно отмечается и не меняет статус проверенного звука. |

Дополнительно выполнен отдельный реальный прогон: 18 секунд синтетического
звука, шесть каналов, разные центральные каналы, известная задержка 10 мс.
Все 18 контрольных точек выходного WAV получили подтверждение PCM.
Пример графиков и отчёт находятся в `examples/synthetic_10ms_5_1`.
Сверхмалые остатки этого примера объясняются известным точным преобразованием
одного сигнала; переносить эти числа на разные кинофонограммы нельзя.

Установка зависимостей из `requirements.txt` выполнена в новом `.venv`.
Повторный запуск облачного установочного скрипта также прошёл.
Для Windows x64/Python 3.12 проверено разрешение зависимостей в готовые wheels
из PyPI. CMD-файлы сохранены в UTF-8 с CRLF, их пути и обработка ошибок проверены
по коду. **В Windows они не исполнялись:** доступная машина — Linux.

Старые встроенные self-test отдельно прошли: 6 проверок из `self_test_v6_9.py`
и 9 проверок из `self_test_v6_8.py`. Они не входят в число 35 тестов новой сборки.

Реальные фильмовые дорожки пользователя не приложены. Не подтверждены
качество конкретного перевода, идеальное совпадение по всему фильму,
произвольный автоматический монтаж и физическая точность 1 мкс.
Эти ограничения отражены также в основной инструкции и итоговых отчётах.
