# Проверки Modular 6.9.5 — 16.10.2026

Проверки выполнялись в Linux: Python 3.12, NumPy 2.3.5, SciPy 1.17.0,
Matplotlib 3.10.8, FFmpeg 7.1.5. Исходные аудиофайлы во всех проверках сохраняются.

## Причина реального отказа

Воспроизведена отмена 19 окон на полной присланной карте длиной 5252,01 с.
Старая отмена давала максимальное изменение скорости 2,10596% при пределе 2%.
Исправленная отмена проходит прежнее ограничение. Числовой участок из этого
случая, без названий фильма и личных путей, входит в регрессионный тест.

## Автоматические проверки

- 38 unittest-тестов: TEST_LOG.txt.
- 9 исходных safety/validation-проверок: LEGACY_TEST_LOG.txt.
- 6 исходных проверок микроуточнения: LEGACY_MICRO_TEST_LOG.txt.

Проверены реальные запись/декодирование, сдвиги 6/10 мс, дробные отсчёты,
разная полярность, громкость и частотные миксы, тишина, периодический тон,
посторонний звук, общий закон времени для шести каналов, 44,1/48 кГц и float32.
Тесты проверяют реальный числовой отказ отмены, точное сохранение
независимой компоненты и выявление плохого кандидата до рендера. Отдельно
проверен запуск микроуточнения в новой временной папке только с двумя
аудиофайлами: анализ строится заново, результат остаётся шестиканальным,
обе исходные дорожки сохраняют SHA-256.

## Полные прогоны

Все 12 этапов прежнего интерфейса пройдены на четырёхминутных синтетических
DTS/WAV с шестью каналами и начальным сдвигом 275 мс. Центральный канал
намеренно отличается. Проверены исходные SHA-256, длительность, каналы,
графики и результат PCM. Лог: FULL_PIPELINE_LOG.txt.

    python -m tests.full_modular_smoke NEW_DIRECTORY .275

Полных реальных дорожек фильма в облаке нет. Проверка их готового результата
выполняется при обработке на компьютере пользователя. Корреляционная
оценка меньше отсчёта не является гарантией физической точности 1 мкс.

## Windows 11

CMD-обёртки сохранены с CRLF, UTF-8, поддержкой пробелов и кириллицы в пути.
Запуск — START_WINDOWS.cmd; для малого остаточного сдвига — MICRO_REFINE.cmd.
Зависимости для Python 3.14 x64 ранее проверены по Windows wheels.
Новая программа непосредственно под Windows в этой среде не запускалась.
