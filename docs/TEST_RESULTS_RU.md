# Проверки Modular 6.9.8 по отчёту 22.10.2026

Linux, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8,
FFmpeg 7.1.5. Непосредственного запуска Windows 11 и foobar2000 здесь не было.

## Автоматические проверки

73 unittest-теста, 9 исходных safety/validation-проверок и 6 исходных
проверок микроуточнения прошли. Журналы: `TEST_LOG.txt`,
`LEGACY_TEST_LOG.txt`, `LEGACY_MICRO_TEST_LOG.txt`.

Дополнительные регрессии проверяют:

- реальные округлённые узлы карты на 40-й минуте и сохранение кубической кривой;
- отклонение настоящего обратного интервала и скачка 10 мс;
- сохранение проверенного базового PCM при исключении дополнительного поиска,
  с записью и декодированием настоящего S16 WAV;
- отсутствие копии исходника при нулевой карте, отказе всех трёх рендеров
  и рендере без подтверждённого улучшения;
- отсутствие нового WAV при отказе PCM, `output_file: null` в отчёте;
- удаление только созданных текущим запуском отклонённых файлов;
- сохранность исходника и прежних результатов при перемещении принятого файла;
- согласованные частотные якоря и жёсткую границу при противоречии;
- видимость всех вложенных PCM-слоёв для проверок и кеша;
- одинаковую запись трёх PCM-слоёв во всех шести каналах;
- локальную отмену вложенных непроверенных слоёв с сохранением защищённой базы;
- сохранение уже улучшенного WAV при исключении дополнительной фазы.

## Воспроизведение сбоя на полной карте

До исправления три варианта отмены локальных поправок падали на полных
числовых картах из отчёта пользователя. После исправления все три
завершаются, настоящие ограничения монотонности и скорости остаются включены.
Повторная загрузка двух карт объединила 655 и 696 избыточных узлов;
значения времени эталона в исходных узлах совпадают без измеримой разницы float64.
Короткий тест использует только обезличенный числовой отрывок ошибки.

шестиканальных DTS/WAV со сдвигом 275 мс, разным центральным каналом

## Границы проверки

Полных звуковых дорожек фильма в облаке нет. Численная причина сбоя проверена
на полной карте времени; звуковой результат — на присланных фрагментах.
Полный фильм на Windows требует отдельного запуска. На некоторых проверенных
окнах остаётся измеримый сдвиг, поэтому эта сборка не объявляется идеальной
на всех участках фильма. Различающиеся миксы, тишина и неоднозначные сигналы
не дают доказательства точности в одну микросекунду.

Личные пути, пользовательские аудиофрагменты и исходные отчёты в репозиторий
не включены. Архив программы содержит только код, документацию и численные
результаты проверок.

```text
python -m unittest discover -s tests -t . -v
python self_test_v6_8.py
python self_test_v6_9.py
python -m tests.full_modular_smoke NEW_DIRECTORY .275
python -m tools.verify_diagnostic_clips CLIPS_DIR NEW_RUN_DIR --step 1
python -m tools.compare_diagnostic_runs CLIPS_DIR OLD_RUN NEW_RUN RESULT_JSON
```
