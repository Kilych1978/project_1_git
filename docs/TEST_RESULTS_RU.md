# Проверки Modular 6.9.10 — 11.11.2026

Linux, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, FFmpeg 7.1.5.
Прямого запуска на Windows 11 здесь не было.

## Регрессии и реальные WAV

80 unittest-тестов прошли. Дополнительно 13 целевых проверок PCM-слоёв,
восстановления окон и записи шестиканального WAV прошли после последнего
исправления подсчёта вложенных изменений. Исходные 9 safety/validation-тестов
и 6 микро-тестов также прошли.

Новые регрессии проверяют:

- восстановление ВСЕГО контрольного окна, включая отличающуюся внутреннюю
  карту времени и два вложенных PCM-слоя;
- побитовое сохранение шести каналов в восстановленном окне и неизменность
  удалённой полезной поправки;
- сериализацию полного плана, точное воспроизведение восстановленного PCM
  после загрузки и сохранность кеша незатронутых окон;
- одинаковое обнаружение изменения bare-TimeMap и четырёх пустых PCM-оболочек;
- полный вызов `refine_rendered_audio`: небезопасный план исправлен ДО записи,
  записан один настоящий шестиканальный S16 WAV, все исходные и защищённые
  проверки проходят, исходник не изменён;
- включение реально отказавшего окна и звука отклонённого кандидата в диагностику.

Проверка прежней локальной отмены теперь оценивает фактическое восстановленное
аудио. Один узел номинальной карты не описывает амплитудное перекрытие двух
планов; точный план сериализован в `fine_map`.

Журналы: `TEST_LOG.txt`, `NATIVE_TEST_LOG.txt`, `LEGACY_TEST_LOG.txt`,
`LEGACY_MICRO_TEST_LOG.txt`.

## Данные пользователя

Проверены CRC шести ZIP и SHA-256 всех 130 восстановленных файлов.
Выполнена проверка на десяти доступных восьмисекундных моноотрезках.
Сохранены координаты полного фильма, его карта времени, исходная фаза сеток
и защищённая базовая карта. Сетки коротких фрагментов не начинались заново с нуля.

После сквозной проверки записаны настоящие S16 WAV и выполнены 5198 сравнений
записанного PCM с исходником и защищённой базой: ноль отказов.
В 3004 сравнениях подтверждено улучшение; медианный остаток этих сравнений
0,002909 мс. Это не 3004 независимых места: использованы разные сетки
и две базы сравнения. Числа и область проверки:
`REPORT_ANALYSIS_20261111.json`.

Последнее исправление подсчёта вложенных оболочек дополнительно проверяется
на тех же записанных WAV. Звука из части реально отказавших окон полного
запуска в присланных ZIP нет: новый сборщик диагностики устраняет этот пробел.

## Полный режим

Журнал `FULL_PIPELINE_LOG.txt` относится к проверке полного режима на
синтетической четырёхминутной паре DTS и шестиканального S16 WAV.
Прогон прошёл все 12 этапов: 483 подтверждённых улучшенных окна, один
итоговый шестиканальный S16 WAV без удвоения размера и с корректной
длительностью; исходные контрольные суммы сохранены, создано не менее
13 графиков. Номинальный исходный сдвиг — 275 мс.
Тест выполнен за 17,12 минуты на облачной машине; это не прогноз времени
для фильма на пользовательском ноутбуке.

## Что не подтверждено

Полный новый WAV фильма пользователя не записывался: полных дорожек в облаке
нет. Локальные тесты и числовой разбор объясняют найденный отказ, но не
доказывают прохождение всех ещё не доступных аудиоокон полного фильма.
Порог одного отсчёта, уникальность, корреляция и проверка фактического WAV
не ослаблены. Универсальное идеальное совпадение разных миксов не обещается.

Обычный запуск заново читает выбранные аудиодорожки. Сохранённая карта
пользователя использовалась только для диагностики; старая папка результата
программе не нужна. Пользовательский звук и личные пути в сборку не включены.

```text
python -m unittest discover -s tests -t . -v
python self_test_v6_8.py
python self_test_v6_9.py
python -m tests.full_modular_smoke /tmp/wavesync-smoke .275
```
