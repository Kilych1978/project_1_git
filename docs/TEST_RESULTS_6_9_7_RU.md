# Проверки Modular 6.9.7 — 21.10.2026

Linux, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8,
FFmpeg 7.1.5. Непосредственного запуска Windows 11 и foobar2000 здесь не было.

## Автоматические проверки

61 unittest-тест, 9 исходных safety/validation-проверок и 6 исходных
проверок микроуточнения прошли. Журналы: `TEST_LOG.txt`,
`LEGACY_TEST_LOG.txt`, `LEGACY_MICRO_TEST_LOG.txt`.

Проверяются изменения скорости, дробные сдвиги, 6/10 мс, другой микс,
полярность, периодические сигналы, тишина, монтаж, шесть каналов, 44,1/48 кГц,
нативная запись WAV, разрядность PCM и счётчики большого RF64.
Новые проверки отдельно покрывают:

- сохранение ранее улучшенной сцены при отказе нового кандидата;
- точность замены кубической карты между якорями и после JSON;
- одинаковые веса PCM-соединения во всех каналах и соответствие реального
  S16-файла виртуальной модели с погрешностью не более одного отсчёта;
- повторный короткий анализ при размытии широкого окна из-за скорости;
- отклонение плохой PCM-вставки с сохранением хорошей независимой вставки;
- отдельное имя уточнённого файла при наличии принятого основного WAV;
- ограничение строки прогресса шириной терминала и редкий вывод в журнал;
- полноту диагностического пакета после финального JSON и при ошибке;
- деление большого отчёта без потери байтов на самостоятельные ZIP;
- точное последовательное извлечение первого канала по PCM-счётчикам.

## Полный запуск

`FULL_PIPELINE_LOG.txt` — полный прогон 12 этапов на новых четырёхминутных
шестиканальных DTS/WAV со сдвигом 275 мс и разным центральным каналом.
Проверены SHA-256 обоих исходников, длительность, каналы, S16, обычный RIFF,
размер, исходные графики и фактический PCM-результат: 483 изменённых
проверенных окна, медианный остаток около 0,000000820 мс.
Это функциональный тест, не полный прогон фильма пользователя.

## Воспроизведение и границы проверки

Полных дорожек фильма в облаке нет. Проверены присланные фрагменты;
результат полного фильма на Windows 11 ещё требует пользовательского запуска.
Неизмеримые окна, тишина и отличающийся звук не объявляются идеальной
синхронизацией. На границах PCM-соединений применяется короткое смешивание;
проверка временного сдвига не является гарантией субъективной неразличимости
всех каналов во всех непроверенных промежутках.

Звук, личные пути и исходные пользовательские отчёты в репозиторий не включены.
Результаты сравнения публикуются только численно.

```text
python -m unittest discover -s tests -t . -v
python self_test_v6_8.py
python self_test_v6_9.py
python -m tests.full_modular_smoke NEW_DIRECTORY .275
python -m tools.verify_diagnostic_clips CLIPS_DIR NEW_RUN_DIR --step 1
python -m tools.compare_diagnostic_runs CLIPS_DIR OLD_RUN NEW_RUN RESULT_JSON
```

Новые запуски заново читают выбранные дорожки. CMD-файлы сохранены в UTF-8
с CRLF; сборка проверяется после распаковки в путь с кириллицей и пробелами.
